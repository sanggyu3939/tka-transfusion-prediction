# Data Description

## Overview
This dataset includes patients who underwent total knee arthroplasty (TKA) between 2016 and 2025.

## Data Availability
The dataset contains sensitive patient information and cannot be publicly shared due to institutional and ethical restrictions.

## Variables
- Age, sex, BMI
- ASA physical status
- Platelet count
- Anticoagulation use
- Tranexamic acid use
- Type of anesthesia
- Navigation use
- Preoperative hemoglobin

## Outcome
Postoperative transfusion (binary)

## Note
The code can be applied to similarly structured datasets.
